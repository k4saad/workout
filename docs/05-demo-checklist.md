# Exercise demo checklist

One curated YouTube URL per exercise, filled in by you.

**These are deliberately blank.** An invented link is worse than no link: it
cannot be verified, and a wrong demo teaches the wrong movement. Do this over
a week, a few at a time, and prefer coaches who show the *solo home-gym*
version where it differs — bailing out of a squat, floor pressing, setting
catch pins.

To fill one in, edit `data/exercises.json`, set `media.youtubeUrl`, then:

```bash
cp data/exercises.json app/assets/exercises/exercises.json
```

`media.youtubeStartSec` skips past the intro.

## Where the stills came from

`yuhonas/free-exercise-db`, released under **The Unlicense** (public domain).
Verified two ways: `LICENSE.md` in that repository carries the Unlicense text,
and GitHub's own licence detection reports `unlicense`. Each bundled image
records its source id in `media.stillLicence`.

**Never** scrape MuscleWiki, GymVisual, Everkinetic-derived sets or the
RapidAPI ExerciseDB bundles. Those are copyrighted, and "it is only for me"
does not change the copying.

### Matching was not free

The first matching pass stripped "barbell" and "dumbbell" as noise words and
confidently matched **barbell bench press** to a photo of a *dumbbell* bench
press at 0.95 similarity — the main lift of the programme, illustrated with
the wrong implement. The matcher now treats the implement as a veto: if both
names state one and they disagree, it is not a match at any score.

That is why 37 exercises have no picture. A cue list with no image is fine;
a mislabelled demo teaches the wrong movement.
